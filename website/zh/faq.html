常见问题

浏览器里的游戏串流，一文说清

关于 MoonlightWeb 的常见问题——延迟、编解码器、设备、互联网远程游玩、安全。没找到你的答案？到 GitHub 提问。

基础

MoonlightWeb 是什么？

一个免费、开源（GPL-3.0）、自托管的服务器，把你的游戏 PC 串流到任何带浏览器的设备——手机、平板、笔记本、电视。你只需在游戏 PC 上安装一个小服务器，它会自己捕获并编码这台机器；其他所有设备只要打开一个网址。客户端无需安装任何东西。

MoonlightWeb 真的免费吗？

是的。采用 GPL-3.0 许可，无账户、无订阅、无付费档位。它是自托管的：你的游戏直接从你自己的 PC 串流，绝不经过任何第三方云。

使用它需要什么？

两样东西：游戏 PC（Windows、macOS Apple Silicon 或 Linux）且 GPU 支持编码，以及任何带现代浏览器的客户端设备——Chrome、Edge、Safari 或 Firefox。

无需第二个串流服务器：MoonlightWeb 会捕获并编码它所安装的那台机器。如果你在别处已经跑着 Sunshine、Wolf 或 MultiSeat，这些主机可以在同一个页面里被发现并配对。

我需要在手机、平板或电视上安装应用吗？

不需要。客户端是 100% 网页的：你只需在浏览器里打开一个网址。唯一的安装是游戏 PC 上的服务器本身。

MoonlightWeb 和 moonlight-web-stream 是同一个项目吗？

不是。它们是两个名字相近、彼此独立的开源项目。moonlight-web-stream 是一个用于 Sunshine 主机的网页客户端。MoonlightWeb（本站，linckosz/moonlight-web）拥有自己的采集和编码引擎：安装在游戏 PC 上，它就能独立串流这台 PC，无需 Sunshine。它也可以与 Sunshine 配对，以及 Apollo、Wolf 和 MultiSeat。

设备

我能在 iPhone 或 iPad 上玩 PC 游戏吗？

能——在 Safari 里打开网址，无需从 App Store 下载。你的手机化身完整客户端：多点触控触控板（1 指瞄准，2 指滚动和缩放）、带修饰键的原生虚拟键盘，以及游戏手柄——最高 120 fps，Wi-Fi 延迟低于 20 毫秒。

我能在智能电视上玩吗？

任何带现代浏览器的设备都能作为客户端。在电视上，体验取决于内置浏览器；带硬件视频解码的较新浏览器效果最佳，再加一只有线或蓝牙手柄，客厅设置就完整了。Android TV 盒子同样可用：已用 TV Bro 浏览器测试，遥控器既能浏览页面，也能操控串流。

它支持游戏手柄吗？

支持——Xbox 和 PlayStation 手柄均可使用，含振动，此外还有键盘、指针锁定鼠标、触摸触控板和虚拟键盘。大多数其他手柄可自动识别，任何手柄都可在设置中重新映射（Switch Pro 手柄：请用 USB 连接）。在触摸屏上，手边没有手柄时可使用内置屏幕手柄。

赛车方向盘、飞行摇杆和航模遥控器同样可用：在电脑上的 Chrome 或 Edge 中，MoonlightWeb 自己的主机可以把真实设备交给游戏，所有轴都在，方向盘在 Windows 和 Linux 主机上还有力反馈。

性能

我能期待怎样的延迟？

Wi-Fi 下低于 20 毫秒。MoonlightWeb 使用带自适应拥塞控制的 WebRTC UDP 传输，为快节奏游戏而设计，而非远程桌面用途。

支持哪些分辨率、帧率和编解码器？

最高 4K HDR、最高 240 fps，支持 H264、HEVC 和 AV1——通过 WebCodecs 在浏览器中硬件解码。你的浏览器无法解码的编解码器选项会自动置灰。HDR 显示器可获得真正的 HDR 输出。

什么是 Video Enhancement（视频增强）？

在浏览器中通过 WebGL2 或 WebGPU 运行的 GPU 放大与锐化（MoonlightWeb 自研放大算法）。你可以在 4G 或酒店 Wi-Fi 下以 720p 串流，却显示接近 1440p 的画质——而且完全不给游戏 PC 增加负担，因为它在客户端运行。

什么是 MWSR？

MWSR（MoonlightWeb Super Resolution）是 MoonlightWeb 自研的实时放大算法，视频增强在 Auto 模式下使用的就是它。它只凭当前这一帧，用一次 GPU 渲染把每帧解码画面重建为屏幕尺寸：不依赖历史帧，也不使用神经网络，因此不会增加一帧延迟。在 iPhone 13 Pro 上，它每帧最多增加约 2 毫秒。在入门级手机（Mali-G57）上，它每帧增加 4 毫秒或更多，难以维持每秒 60 帧，因此 Auto 模式不会在这类手机上启用它。它锐化边缘，光晕很少，能缩小比屏幕更大的串流画面，也支持 HDR。代码以 MIT 许可证开源，任何程序都可以使用。在你自己的 GPU 上将它与 FSR1、NIS 和 SGSR1 对比。

遇到严格防火墙或酒店 Wi-Fi 会怎样？

先用 UDP 以获得最低延迟。在屏蔽 UDP 的网络上，串流会自动回退到 TCP，仍是直连，从不经过中继。只放行网页端口（80 和 443）的网络仍可能阻断它：这时请使用主机的直连地址。

互联网远程游玩与安全

我如何在外地通过互联网游玩？

串流是浏览器与 PC 之间点对点的 WebRTC 直连。你的电脑会保持一条到介绍服务器的出站连接，并通过一个专属链接被访问——没有公开子域名、不暴露 Web 端口；已持有子域名的安装可继续使用至 2027 年 2 月。你也可以使用自己的域名和证书。

它安全吗？我的串流去了哪里？

MoonlightWeb 是自托管的：串流直接从你的 PC 到你的浏览器，绝不经过任何他人的云。主机通过 PIN 码配对，接入链接由我们维护的证书以 HTTPS 提供——不会为你的机器签发任何证书，也不会公开与它有关的任何信息。

MoonlightWeb 底层是如何工作的？

一个小型 C++/Qt 服务器运行在游戏 PC 上。它捕获一块 GPU 表面，并在持有 WebRTC 连接的同一个进程里直接交给 GPU 编码器——没有回环网络跳、没有 RTP、没有 FEC——然后通过 WebRTC 把视频、音频和输入送到浏览器。在浏览器中：WebCodecs 解码，WebGL2 或 WebGPU 渲染，浏览器自带的 WebRTC 播放器播放 Opus 音频。

若是你配对的主机，同一个服务器会内嵌 moonlight-common-c，用 GameStream 协议（RTSP/RTP/ENet）与它通信，再以同样方式转发该串流。

为什么我的系统会对安装程序发出警告？

因为安装程序没有用付费证书签名——Windows SmartScreen 和 macOS Gatekeeper 会标记一切它们不认识的东西，无论是否已签名、是否安全。代码是公开的，你可以确切地看到自己安装的是什么。

在 Windows 上：点击更多信息，然后仍要运行。

在 macOS 上可以完全避开警告——它只针对浏览器下载的文件：

brew install --cask linckosz/tap/moonlightweb
curl -fsSL https://moonlightweb.top/install.sh | bash

或者保留已下载的文件，在系统设置 → 隐私与安全性 → 仍要打开中放行。详见 macOS 指南。

MoonlightWeb 会收集哪些数据？

不收集任何能识别你身份的信息。无需注册账号，你的串流直接从你的电脑到你的浏览器——从不经过我们。

在应用中。它会发送关于串流的匿名统计：分辨率、帧率、编解码器、连接方式、会话时长，以及 MoonlightWeb 版本和操作系统。从不包括你的电脑名称、账号、你启动的内容，也不包括你的 IP 地址。应用设置中的一个开关可立即将其关闭；关闭也不会改变其他任何事情：串流和更新完全照常。每一位登录的用户都能在那里看到到底统计了什么，受邀的玩家则可以通过加入页面上的 Cookie 按钮查看同样的说明。

当你从互联网游玩时。要让浏览器找到你的电脑，有两件事必须发生，它们都不是统计。你的电脑会保持一条到我们介绍服务器的出站连接，该服务器因此知道它的公网地址及其在线时间——但从不知道你在玩什么，也不知道你是谁。此外，两端都会向 STUN 服务器（同样是我们的）查询自己的公网地址，因为两台机器正是这样彼此直接定位的。这两点都写在应用启用互联网访问前向你展示的协议中；只要该功能处于关闭状态，它们都不会发生。

在本网站。访问量由我们自己托管的无 Cookie 统计工具（Umami）统计：没有 Cookie、没有广告、不跨站追踪，且不保存你的 IP 地址——它会被转换成每天都变化的一串数字。这就是为什么这里没有 Cookie 横幅。本站在你浏览器中保存的只有你选择的语言。

开始使用

在 Windows 上安装向导式安装程序——一个向导，别的都不用配。 在 macOS 上安装Apple Silicon 指南，附 .pkg 安装程序。 在 Linux 上安装.deb、.rpm 或便携 AppImage。
