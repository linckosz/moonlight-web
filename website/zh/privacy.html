MoonlightWeb 会发送什么

MoonlightWeb 运行在你自己的电脑上。串流的画面、声音和输入直接从你的游戏 PC 到你的浏览器，从不经过我们的服务器。本页列出所有会到达我们这里的内容，以及如何关闭。

应用会发送什么

只有官方构建才会发送这些内容。你自己编译的构建不会向我们发送任何内容；它的更新检查会访问 GitHub。

  • 更新检查：最多每六小时一次，把版本、操作系统和处理器类型（x64 或 ARM）发送到 updates.moonlightweb.top，它会返回 GitHub 上的最新版本。
  • 会话统计：串流开始和结束时，发送它的概况：分辨率、帧率、编解码器、HDR 和 4:4:4、码率、传输方式（后端、传输协议、局域网或互联网）、设备类型、所有者或访客，以及持续时间；如果从未开始，则发送错误代码。同时附带版本、操作系统和处理器类型。不包含主机名、账户、应用或游戏，也不包含任何地址。
  • 错误报告：串流遇到错误后，最多每 15 分钟发送一份报告，包含 PC 和参与的浏览器页面的错误与警告行，以及构建版本和串流概况。地址、机器名和用户名、密钥、链接以及应用标题会先在你的 PC 上删除，我们的服务器还会再过滤一次。报告最多保存 90 天。

不保存任何地址。统计数据进入我们自己的分析系统，以每天更换的哈希表示，接收它们的服务器不保留访问日志。

要关闭，请在应用中使用 设置 › 隐私。它会一次关闭全部三项，立即生效，并且只能在 PC 本机上更改；之后更新检查会直接访问 GitHub。

在 settings.json 中，"update_relay_enabled": false 会让更新检查改为直接访问 GitHub，"session_metrics_enabled": false 会停止统计和错误报告。环境变量 MW_NO_TELEMETRY=1 会停止一切，包括更新检查。

互联网访问

互联网访问默认关闭，直到所有者在安装程序或管理页面中开启。

开启后，PC 会与 stream.moonlightweb.top 保持一条连接，由它把浏览器介绍给 PC。该服务器转发连接建立过程，其中包含双方的地址。保护串流的密钥由你 PC 的配对密钥担保，而该服务器从未见过这个配对密钥，因此它无法插入到中间。双方连接后，它就退出通信路径。

在 PC 和浏览器连接期间，它能看到它们的地址，但不会记录任何一个。

它只保存 PC 的标识符、其所有者令牌的哈希，以及创建时间和最后在线时间（精确到小时）。不记录任何消息。

反馈

只有当所有者在服务器设置中写下消息并点击 发送 时，才会发送反馈。内容包括消息、填写了的电子邮件地址，以及仅在勾选复选框时附带的版本、版本类型和操作系统类别。

反馈会发到一个由版主阅读的私有 Discord 频道。我们的服务器不保留副本。

其他服务

  • GitHub：除非设置了 MW_NO_TELEMETRY=1，只要更新检查不经过 updates.moonlightweb.top，它就会直接访问 api.github.com，最多每六小时一次。
  • 如果 PC 上还没有 ViGEmBus 手柄驱动，Windows 安装程序会从该项目的 GitHub 发布页下载它。卸载 MoonlightWeb 后，该驱动仍会保留。
  • 会话来源：如果所有者设置了 "session_location_enabled": true，访客的地址会发送到 ipwho.is，以便管理页面显示城市。默认关闭，且从不发送私有地址。
  • 本网站使用我们自己托管的无 Cookie 统计。其下载按钮会从你的浏览器向 GitHub 查询最新版本。MWSR 页面只在你点击其按钮时才发送测量结果，且不含你的地址。
